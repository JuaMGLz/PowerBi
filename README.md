# 📊 Power BI - Entorno de Trabajo Web

Página web estática desarrollada para documentar, explorar y presentar el entorno de trabajo de Microsoft Power BI. Este proyecto sirve como una guía visual y estructurada sobre las herramientas de Business Intelligence (BI) y el análisis de datos.

Es un proyecto ideal para demostrar la capacidad de maquetar información técnica de manera clara y accesible mediante tecnologías web estándar.

## 🚀 Características Principales

- **Estructuración de la Información:** Maquetación clara y semántica para explicar el funcionamiento y el entorno de Power BI.
- **Enfoque en Data Analytics:** Orientado a destacar conceptos clave de Business Intelligence, visualización de datos y creación de reportes.
- **Interfaz Web Accesible:** Diseño y estructura en formato web para que la información o los posibles dashboards embebidos sean fácilmente consultables desde el navegador.

## 🛠️ Tecnologías y Herramientas

- **Lenguaje Principal:** HTML5 (Estructura semántica y presentación del contenido).
- **Herramienta de BI de Referencia:** Microsoft Power BI.
